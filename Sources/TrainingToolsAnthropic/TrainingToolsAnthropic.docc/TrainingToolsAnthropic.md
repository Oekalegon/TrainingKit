# ``TrainingToolsAnthropic``

Adapts TrainingKit's tool registry to the Anthropic Messages API.

## Overview

`TrainingToolsAnthropic` depends on `TrainingTools` and is available on all supported platforms. It renders the provider-neutral tool schemas into the Messages API `tools` array and runs the tool-use loop.
