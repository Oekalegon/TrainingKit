# ``TrainingToolsFoundationModels``

Adapts TrainingKit's tool registry to Apple's on-device FoundationModels framework.

## Overview

`TrainingToolsFoundationModels` depends on `TrainingTools` and requires iOS 26+/macOS 26+. It maps the tool registry onto FoundationModels' `Tool` protocol and `@Generable` types.
